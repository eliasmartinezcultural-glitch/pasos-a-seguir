# El Camino del Chañar
**Ocarina LAB · Ocarina Producciones**

Aventura histórica interactiva ambientada en San Patricio del Chañar, Neuquén.

## Estado
Prototipo jugable inicial (Prólogo). Incluye:
- Protagonista ficticio: Mateo.
- Escena de llegada y decisiones interactivas.
- Variables de recorrido: vínculos, conocimiento y memoria.
- Libreta narrativa que registra decisiones.
- Diseño adaptable a celulares y computadoras.
- Sin cuentas, servidor, base de datos ni dependencias de JavaScript.

## Cómo probarlo
Abrir `index.html` en un navegador. Para publicarlo con GitHub Pages:
1. Entrar en Settings del repositorio.
2. Abrir Pages.
3. En Build and deployment elegir Deploy from a branch.
4. Seleccionar `main` y `/ (root)`, guardar.
5. Esperar la publicación y abrir la dirección que informa GitHub Pages.

## Criterio histórico obligatorio
Mateo, sus diálogos y las situaciones personales son ficción. No representan testimonios reales ni deben atribuirse a personas históricas.

Las fechas, los acontecimientos, las instituciones, los lugares y los datos sobre San Patricio del Chañar deben incorporarse únicamente después de una verificación documental. Cada misión histórica deberá tener una ficha con:
- Acontecimiento y fecha.
- Fuente primaria o institucional.
- Personas y lugares reales.
- Elementos recreados.
- Límites de lo que puede afirmarse.

El prólogo actual es una introducción narrativa ficticia y no afirma que Mateo haya participado en un acontecimiento histórico real.

## Archivos
- `index.html`: estructura del juego.
- `styles.css`: diseño visual responsive.
- `app.js`: escenas, decisiones y progreso.
